Где затупил:
- С шаблонными строками главное было не забыть про обратные кавычки `` ` `` вместо обычных, иначе `${...}` не подставляется.
- Во вложенном объекте товара сначала писал `product.cpu`, а нужно `product.specs.cpu` — характеристики лежат во вложенном объекте.
- В деструктуризации удобно сразу достать `const { name, email, role } = user`. Старый способ оставил рядом в комментарии для сравнения.
- В заказе считал сумму прямо в цикле по `order.items`, заодно складывая общий итог в отдельную переменную.
