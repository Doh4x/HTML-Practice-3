Где затупил:
- Постоянно держал в голове правило "исходный массив не трогаем": `map` и `filter` сами создают новый массив, а вот перед `sort` обязательно делал копию через `slice()`.
- В каталоге по категориям сделал отдельную проверку на пустую категорию, чтобы интерфейс не ломался, если товаров нет.
- В таблице заказов количество и сумму считал из вложенного массива `items`, а не хранил заранее.
- В чистых функциях главное было, чтобы функция зависела только от аргументов и возвращала новый результат — никаких обращений к глобальным переменным внутри.
- Имя с большой буквы делал через `charAt(0).toUpperCase() + slice(1)`.
