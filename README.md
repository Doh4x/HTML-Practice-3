Где затупил:
- В фильтрации сначала сравнивал строки напрямую и поиск зависел от регистра. Привёл и запрос, и название к `toLowerCase()`.
- В поиске по id `find` возвращает сам объект (или `undefined`), а не индекс — поначалу путал с `indexOf`.
- В преобразовании цен главное было не трогать исходный массив: `map` сам создаёт новый, так что `prices` остаётся прежним.
- В сортировке `sort` меняет массив на месте, поэтому перед сортировкой делал копию через `slice()`, чтобы кнопка "Исходный" всё ещё показывала исходный порядок.
