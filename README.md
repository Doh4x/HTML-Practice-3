Классический мем «Прикол за 300» — это народная игра-дразнилка, построенная на рифме со словом «триста». Суть в том, чтобы заставить собеседника первым сказать «триста», а затем парировать знаменитой ответной рифмой: «— Отсоси у тракториста!»Как работает приколВы просите собеседника назвать любое число или спрашиваете: «Сколько будет 100 + 200?»Как только он произносит «300», вы с триумфом выдаете шуточную рифму.
